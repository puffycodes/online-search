# Features of Hottest Discussions App

- The web page will have an area to display the top discussions.
- The web page will have a button for refreshing the discussions.
- The web page will have a drop-down menu that indicate how many top discussions to retrieve.
    - The default is 10.
    - The drop-down menu will give the options of 10, 25 and 50.

- Upon starting, the web page will not display any top discussions.
- The web page will use the hottest_tech_discussions.py script to retrieve the top discussions.
